# AgriHot 线上主题数据核验

核验日期：2026-10-22。来源：[主题页](https://agrihot.com/tags)、[标签接口](https://agrihot.com/api/v1/tags)、[站点统计](https://agrihot.com/api/v1/stats)、[公开文章列表](https://agrihot.com/api/v1/items?page=1&page_size=100)，并与用户提供的 `agrihot-tag-mapping.csv` 比对。

读取公开文章列表全部 56 页，取得 5,537 个不同文章 ID，无重复；分类计数、精选计数以及重新计算的 7,888 个标签的逐词文章数均与接口一致。读取前后文章数、标签总数和最新文章 ID 未变。这是一次线上观测，不是数据库事务快照。

原方案中的「900+ 标签」「约 500 个低频词」不是当前全站规模。CSV 的 900 个不同词只是一份选定词表。当前源码中，`/stats.tags` 统计全部 `Tag` 行，`/tags` 只统计存在文章关联的词，两者不能混为同一个指标。

7,142 个低频词不适合平铺成导航；它们仍然可能是有效的品种、机构、技术或实体，不能仅因低频就全部删除或设为同义词。

## 2. CSV 的词表覆盖

900 个词中有 863 个在线上作为独立标签出现，另 37 个未出现。863 / 7,888 = **10.94% 的标签词面覆盖**。命中的标签关联数为 14,280，占全部 25,795 条关联的约 55.4%；这不是文章去重覆盖率，也不是分类准确率。

各行不可相加作为文章总数。I 的 2,984 篇中有 2,004 篇还命中其他一级，技术入口和产业入口必须允许同时找到同一文章。

I1「智慧农业总论」候选达到 1,907 篇，但「智慧农业」标签本身就覆盖 1,728 篇，其中 1,105 篇还命中其他一级。这不能说明有 1,907 篇总论文章；I1 应收总体路径、架构、模式或转型讨论，不能成为所有带「智慧农业」标签文章的默认主归属。

未命中的 528 篇中，报道 325、论文 178、政策 25。其中 71 篇含有「论文」标签、39 篇含有「中国农科院」标签、25 篇含有「成果转化」标签。这说明需要补内容证据，不应为了追求覆盖率而把机构词和类型词直接转成主题。

## 4. 真实文章暴露的分类问题

| 文章 | 已有标签中的信息 | 原 CSV 精确命中的后果 | 回填应补足什么 |
|---|---|---|---|
| [湖羊行为检测模型](https://agrihot.com/items/5534) | 农业人工智能、智慧养殖、目标检测、湖羊 | 命中 I2；缺少畜牧候选 | 结合标题摘要识别湖羊与养殖行为，增加 C2 / C6 候选，再决定主辅 |
| [小麦渍害调控识别](https://agrihot.com/items/5535) | 智慧农业、农业遥感、作物表型、无人机多光谱、小麦渍害 | 命中 I1 / I3；「小麦渍害」不是字典的「小麦」，漏掉 A2 | 从标题摘要确认小麦对象，保留遥感辅主题 |
| [温室番茄环境调控](https://agrihot.com/items/5536) | 智慧农业、设施农业、环境调控、温室番茄、智能决策 | 命中 I1 / B7；未因「温室番茄」进入 B1 | 以设施环境调控为主，同时保留番茄对象词，避免穷举全部组合词 |

上述建议是对标题和已收录摘要的阅读判断，不作为全站分类准确率样本。尤其不能把所有「智慧养殖」一律补到畜牧，也不能把所有「无人机」一律归遥感。

另有两种情况需要在回填前识别：

- [农业科技合作协议报道](https://agrihot.com/items/5433)的标题和摘要都讨论农业合作，现有标签却是「石墨烯膜 / 二维材料 / 材料科学」，且评分为 0。应进入内容与标签冲突复核，不能据此直接认定为非农业文章；本次未确定错标原因。
- [英国公共建筑改造论文](https://agrihot.com/items/5188)的标题和已收录摘要讨论建筑改造与成本决策，未给出农业应用证据。应先判断收录范围，不为了提高覆盖率就归入农业 AI 或农业碳频道。

## 6. 对升级顺序的调整

1. 先建立受控主题与分类记录，再做标签词面的清洗。保留原始输入和旧链接，新增规范词及别名，避免一次性删除长尾而失去回溯依据。
2. 历史回填使用「旧标签候选 + 标题 / 摘要证据 + 冲突复核」。对外文内容同时利用原文与已收录中文摘要，规则不能只识别中文词。
3. 给主题、技术、区域、机构和内容类型分开建规则。先补「精准农业」「成果转化」「作物表型」等高频缺口；「农业科技」等泛词保持弱证据。
4. 导航优先展示数字农业、投入品与装备、资源环境、大田作物等入口；保留 10 个一级的完整领域覆盖。畜牧与水产的候选量较少，需先补对象词和正文证据，再决定二级的首屏展示，不能据现有词表命中量断言真实内容只有这些。
5. 62 个二级先作为候选字典，不强制全放到首屏。低量节点可放在父级页展开区，分类语义和稳定链接不随篇数频繁变动。
6. 增加农业相关性检查和内容/标签冲突标记，保留「待分类 / 待细分」。3,149 篇跨域命中不等于需要全部人工复核，先通过明确的主辅规则解决，再测量剩余工作量；词表命中率不能替代准确率评估。

完整实现建议见 [主题系统升级建议](taxonomy-upgrade-proposal.md)。
