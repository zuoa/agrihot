# 主题系统实现与验收记录

日期：2026-10-22。规则版本：`2026-10-22.2`。

## 已实现

- `/topic` 两级目录：10 个一级频道、62 个二级方向；文章列表支持内容类型、技术多选、主题内搜索与分页。
- 文章主主题与最多两个辅主题；父级汇总主辅归属并按文章去重；卡片、详情及相关推荐接入主题。
- 独立规则分类：新增与内容变更自动分类，不依赖评分或模型配置；证据不足保留待分类、待细分或待复核状态。
- 后台分类筛选、主辅主题编辑、人工锁定与重分主题；并发内容更新、重评分和回填保护人工归属。
- 版本化 YAML 字典、标签类型与展示状态、机构别名规范化；保留旧标签及组合检索链接，关键词搜索和 Agent 查询支持别名。
- 独立历史回填：预览、批量读取、逐篇事务、断点续跑、版本与输入幂等、变更审计、条件撤回；后台也可运行回填任务。
- 网页、Agent REST 与 MCP 共用主题和技术筛选；新增主题发现接口及 MCP `list_topics` 工具。
- 有效主题页进入 Sitemap；筛选组合设为 `noindex`，不存在的主题路径返回 404。

字典与规则在 [`backend/app/taxonomy.yaml`](../backend/app/taxonomy.yaml) 维护。
结构同步、预览、正式回填与撤回命令见 [README](../README.md#两级主题与分类)。
应用启动只同步结构与目录，历史分类须单独运行回填。
